# Add Chinese Word Skill

When the user provides a Chinese word or phrase, append it to `words.md` using the format below.

## Format

```
## [Character] ([Pinyin])

**Examples:**
1. [Example sentence — pinyin - English translation]
2. [Example sentence — pinyin - English translation]
3. [Example sentence — pinyin - English translation]
```

## Rules

- Use standard pinyin with tone marks (e.g. nǐ hǎo)
- Provide 3 example sentences ordered from simple to complex
- Always append to end of file — do not read `words.md` first, do not check for duplicates

## Trigger

User says "remember this word", "add word", or provides a Chinese word/phrase and asks to record it.
